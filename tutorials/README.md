# Tutorial Nusa (jalur 01–08)

Belajar berurutan dari nol sampai proyek paket. Setiap modul berisi
`README.md` + `main.ns` yang runnable (`nusa run` + `nusa fmt --check`
dikunci `e2e_ecosystem.sh`).

| # | Modul | Topik |
|---|---|---|
| 01 | `01-hello/` | program pertama, build/run/check |
| 02 | `02-variables/` | let, i64/bool/string, array + len |
| 03 | `03-functions/` | fn/return, struct, gambaran modul |
| 04 | `04-generics-traits/` | `fn f<T>`, trait/impl, bounds |
| 05 | `05-match-enum/` | match statement, enum payload |
| 06 | `06-error-handling/` | Option/Result enum 2.0, `?` |
| 07 | `07-closures-concurrency/` | lambda, thread + atomic |
| 08 | `08-package-project/` | `nusa pkg`, `nusa new/test`, registry |

Contoh runnable tambahan (di luar jalur): `examples/` +
`website/examples.html`.
Spesifikasi normatif: `docs/language-spec-2.0.md`.
