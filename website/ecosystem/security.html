Ecosystem / Security Model

Security Model

v2.10.0

Overview

Audit: tanpa eksekusi saat install (tanpa build script/hook); FFI tanpa deklarasi ditolak saat pkg build tanpa native=true (pindai AST gabungan; ad-hoc nusa build tak tersentuh); builtin fs/proses/net tanpa izin = kepercayaan eksplisit ad-hoc. Traversal guard install (pre-list tolak absolut/.., walk tolak subdir/symlink/nama-tak-waras, SEBELUM checksum).
