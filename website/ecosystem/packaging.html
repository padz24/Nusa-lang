Packaging (nusa pkg)

v2.12.0

Overview

Manajer paket sumber-lokal: init/add/remove/update/build/publish. Manifest nusa.toml subset-TOML + semver + SHA-256 + resolver path-deps transitif + lock pin (nama/versi/registry/checksum + [meta] compiler eksak 2.12.0). [capabilities] filesystem/network/process/environment/native (default false). Tarball deterministik (sort/mtime/owner/gzip -n). nusa clean + --profile dev|debug|release (2.13.0).
