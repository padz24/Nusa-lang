Batasan jujur

  • Loopback-only 127.0.0.1, sekuensial, tanpa auth — JANGAN expose publik tanpa reverse-proxy + auth + rate-limit.
  • Memori via polling VmRSS (RLIMIT_AS merusak startup Bionic); tanpa namespace; NPROC tak dipakai.
  • Jaringan TIDAK diblokir; import lokal nonaktif di mode playground.
  • Limit: timeout 10 dtk, memori 256 MB, output 64 KB, body ≤ 256 KB.
  • Verdict: ok | build-fail | timeout | mem-limit | output-limit | signal.

nusa playground --port 8321   # 127.0.0.1 only
