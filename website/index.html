Unduh

Nusa, dari sumber ke biner.

Nusa adalah bahasa compiled modern oleh Padil (Banyumas): tulis .ns, dapatkan executable native lewat LLVM 21.1.8 di Termux Android.

Unduh Nusa 3.0.0 Mulai dari nol
hello.ns
fn main() {
    print("Hello, Nusa!");
}
$ nusa run hello.ns
Hello, Nusa!
biner ~20 KB · acuan bench/ AArch64: ~1,4 dtk

Kenapa Nusa

let x: i64 = 30;Pengetikan statis
i64, bool, string, array, dan alias type yang dicek ketat sebelum biner dibuat.
fn identity(v: T) -> TGenerik dan trait
Monomorfisasi per tipe konkret, dispatch statis, bound T: Show.
let n = parse_age(s)?;Enum, match, dan ?
Option/Result natif, exhaustiveness wajib, propagasi error eksplisit.
chan_len(c: i64) -> i64Konkurensi
Thread, channel, mutex, atomik, plus observability antrean.
nusa pkg buildPaket, registry, FFI
Manifes terkunci, registry file-backed, extern fn C.
nusa lspPerkakas bahasa
Server bahasa 7 fitur, info DWARF -g, dan rantai bootstrap.

Mulai dalam lima baris

pkg install clang cmake llvm
cd ~/nusa && cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j"$(nproc)"
./build/nusa run tutorials/01-hello/main.ns
# Hello, Nusa!
