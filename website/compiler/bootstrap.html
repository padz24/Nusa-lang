Bootstrap & Self-Hosting

v1.20.0

Overview

selfhost/lex.ns: lexer streaming murni-Nusa ekuivalen lexer C++ (differential 33 file) + builtin int_to_str. nusa bootstrap [lex.ns]: Stage 0 (C++) → Stage 1 (biner native) → byte-identik Stage 2 = Stage 0 + cek determinisme 2x + diagnosis byte beda pertama. nusa lex dump kind|lexeme|line|col.

Source

  • selfhost/lex.ns
  • compiler/driver/ (runLex/runBootstrap)
  • docs/bootstrap.md
  • docs/selfhosting.md

Limitations

  • Rantai mencakup lexer SAJA (parser/AST/semantik masih C++). Divergensi hanya di luar korpus valid; performa ~O(n²).

Tests

e2e_bootstrap.sh (4) + e2e_selfhost.sh (5)
