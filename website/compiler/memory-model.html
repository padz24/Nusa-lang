Memory Model

v2.5.0

Overview

Owned values + program-lifetime heap (by-design, bukan bocor). 8 area docs/memory-model.md. Audit 2.5.0: UAF/double-free handle (terbukti ASan sebelum fix) dimitigasi registry + pesan runtime error: invalid handle in <op> + exit 1. Komentar bocor-sengaja diganti status resmi.

Source

  • docs/memory-model.md
  • docs/mem-2.5.md
  • runtime/nusa_rt.c

Limitations

  • Loop alokasi tumbuh per iterasi; tanpa TCO. Batas unsafe eksplisit: builtin/FFI/murni.

Tests
