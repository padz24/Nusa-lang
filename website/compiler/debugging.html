Debugging (DWARF)

v2.15.0

Overview

DWARF via DIBuilder di balik -g: compile-unit malas-per-file, subprogram, line table per statement, lokal skalar (1.18.0) + composite struct/member/offset LP64 + formal params + array bound (2.15.0). Verifikasi llvm-dwarfdump (lldb/gdb tak tersedia di CI).

Source

  • compiler/codegen/ (setDebug/di*)
  • docs/debugging.md
  • docs/debugging-2.15.md

Limitations

  • Satu scope per fungsi; tanpa pretty-printer; tanpa engine interaktif/DAP (butuh kontrol-proses, proyek tersendiri).
