Compiler / Optimizations

Optimizations

v2.4.0

Overview

Pass internal pertama di atas MIR: foldConstants (arith/cmp konstanta; div aman: pembagi nol dan INT64_MIN/-1 tak difold), eliminateDeadCode (murni + tak-dipakai), optimizeFunction/Module (fixpoint berbatas). LLVM tetap optimizer utama (-O0..3/s/z, default O0). Bench: bench/bench.sh + nusa bench + build --stats (2.16.0).

Source

  • compiler/mir/Opt.cpp

Limitations

  • Pass belum di-rewire ke pipeline .ns (nol perilaku; bench .ns identik baseline). Tanpa PGO/LTO. Angka bench perangkat-spesifik.
