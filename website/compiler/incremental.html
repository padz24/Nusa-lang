Incremental Compilation

v1.16.0

Overview

Fingerprint sumber+flag + cache artefak hash IR (.nusa-cache/fingerprint: compiler/target/opt/emit/sysroot/links/modul/IR). Hangat ~7x: clang dilewati bila IR identik. Pesan Fresh <out> (cached) vs rebuilding: ~a.ns. --fresh mengabaikan cache; output hilang → rebuild.

Source

  • compiler/incr/
  • docs/incremental.md

Limitations

  • Frontend selalu jalan (disengaja, murah + sound). Tanpa cache AST/semantik/objek-per-modul; tanpa daemon/watch-mode.

Tests

test_incr (4) + e2e_incr.sh (6)
