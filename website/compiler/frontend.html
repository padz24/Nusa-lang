Frontend (Lexer/Parser/AST/Semantic/TypeChecker)

v2.0.0

Overview

Lexer (token + // ///, keyword extern/enum/match/trait/impl/self/type, reserved async/await) → Parser (lookahead, lambda, match arm, extern fn) → AST (s-expr dump, clone) → Semantic (namespace, scope lambda/arm, builtin registry) → TypeChecker (alias, monomorphisasi, bound, exhaustiveness, ?). Diagnostics file:line:col + snippet + caret + help:.
