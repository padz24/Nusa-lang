Targets & Cross Compilation

v2.18.0

Overview

Host Android AArch64. Cross Linux AArch64/x86-64 via clang --target (compile-only tanpa sysroot; link butuh --sysroot). wasm32 → wasm32-unknown-unknown compile-only alias (2.18.0, tanpa sysroot/WASI/runtime port; ILP32: handle/closure/thread/net tak didukung, komputasi murni saja). Manifest target + flag pkg build.

Source

  • compiler/codegen/ (setTargetTriple)
  • compiler/driver/ (hostTriple/resolveTarget)
  • docs/targets.md
  • docs/wasm-2.18.md

Limitations

  • Tanpa Windows/macOS (dievaluasi, alasan tercatat). Link cross butuh sysroot pengguna.

Tests

e2e_cross.sh (16, incl. ELF via file + IR triple + tolak link/run wasm)
