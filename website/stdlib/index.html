v3.0.0

Sumber: std/*.ns via nusa doc + kurasi. Contoh diuji run di CI.

  • std.collections sejak 1.0.0 — Koleksi dasar di atas array.
  • std.error sejak 1.5.0 — Era struct; 2.0: enum natif + operator ?.
  • std.fs sejak 1.0.0 — File tanpa error rinci (""/false); parse_int_opt/file_read_opt murni-Nusa (1.5.0).
  • std.http sejak 2.9.0 — HTTP/1.x murni Nusa: http_status/http_body/http_get/http_serve_once loopback.
  • std.io sejak 1.0.0 — print/len/assert, I/O dasar.
  • std.math sejak 1.0.0 — abs/min/max/clamp/pow/fact/gcd.
  • std.net sejak 1.10.0 — TCP saja (getaddrinfo, loop-send, recv 1 MiB); 2.0: tcp_listen/tcp_accept + listen_on/accept_one.
  • std.option sejak 1.5.0 — Era struct; 2.0: enum Option<T> { Some(T), None } + kombinator.
  • std.path sejak 1.10.0 — Murni Nusa: basename/dirname/ext/join/normalize.
  • std.process sejak 1.10.0 — process_exit/env/cwd/argc/argv; CLI args via process_argv.
  • std.random sejak 1.10.0 — LCG MMIX + range/bool; builtin random_u64 (/dev/urandom, bukan kriptografis).
  • std.result sejak 1.5.0 — Era struct; 2.0: enum Result<T,E> { Ok(T), Err(E) } + kombinator.
  • std.string sejak 1.0.0 — String buram; 1.19.0: str_index_of/str_contains; builtin str_char_at/slice clamp.
  • std.sync sejak 1.10.0 — with_lock, atomic_inc/dec di atas builtin mutex/atomic.
  • std.system sejak 1.0.0 — Utilitas sistem.
  • std.tasks sejak 2.8.0 — Future/Task/cancel kooperatif di atas thread/channel/atomic; tanpa sintaks async.
  • std.thread sejak 1.10.0 — par_map2 deterministik di atas builtin thread.
  • std.time sejak 1.10.0 — Modul time + builtin time_now_ms/s.
