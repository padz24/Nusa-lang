02 — Variables & types #

Tujuan: let, anotasi i64/bool/string, array + len.

Prasyarat: tutorials/01-hello/.

./build/nusa run tutorials/02-variables/main.ns
# 30
# true
# Nusa
# 1
# 4

Aturan: tanpa anotasi tipe disimpulkan (let x = 10 → i64);

salah tipe ditolak checker (mismatched types).

Index di luar batas = runtime error + exit 1 (bounds check selalu aktif).

Lihat: docs/types.md, docs/arrays.md.

Lanjut: tutorials/03-functions/.

Source code (.ns)

fn main() {
    let a = 10;
    let b: i64 = 20;
    print(a + b);
    let active: bool = true;
    print(active);
    let name: string = "Nusa";
    print(name);
    let numbers: [i64] = [1, 2, 3, 4];
    print(numbers[0]);
    print(len(numbers));
}

Output program

30 true Nusa 1 4

Coba di playground

Exercise

  1. Tambahkan variabel Pi dan cetak 2 * Pi.
    Solusi

    let pi = 3; print(2 * pi); // i64 saja, tanpa float

  2. Apa yang terjadi jika mengakses numbers[99]?
    Solusi

    Runtime error (out-of-bounds) — program exit != 0.
