06 — Error handling (Option/Result 2.0) #

Tujuan: enum natif Option/Result, konstruktor eksplisit,

kombinator, operator ?, match atas varian.

Prasyarat: tutorials/05-match-enum/.

Aturan 2.0 (BREAKING dari struct 1.x — lihat

docs/migration-2.0.md): Option<i64>.None(),

Result<i64, string>.Ok(v) / .Err(e); helper some(v) inferensi;

? hanya atas Result yang sama (operan = return); field

.value/.has_value/.is_ok sudah tidak ada (pakai

match/kombinator).

Lihat: docs/error-handling.md, docs/migration-2.0.md.

Lanjut: tutorials/07-closures-concurrency/.

Source code (.ns)

import option;
import result;
fn parse_age(s: string) -> Result<i64, string> {
    let o = parse_int_opt(s);
    if is_none(o) {
        return Result < i64, string > .Err(str_concat("bad age: ", s));
    }
    match o {
        Some(v) => {
            return Result < i64, string > .Ok(v);
        },
        None => {
            return Result < i64, string > .Err("unreachable");
        },
    }
    return Result < i64, string > .Err("unreachable");
}
fn get_age(s: string) -> Result<i64, string> {
    let n = parse_age(s)?;
    return Result < i64, string > .Ok(n + 1);
}
fn main() {
    print(res_unwrap_or(get_age("41"), 0));
    print(res_unwrap_or(get_age("abc"), 0));
    print(opt_unwrap_or(parse_int_opt("21"), 0));
    print(is_some(parse_int_opt("5")));
}
