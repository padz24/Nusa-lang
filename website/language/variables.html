Language / Variables

Variables

v3.0.0

Overview

Deklarasi dengan let, opsional anotasi tipe. Tipe dasar: i64, bool, string, array [T]. Indexing 0-based dengan cek batas runtime.

Syntax

let a = 10;
let b: i64 = 20;
let active: bool = true;
let name: string = "Nusa";
let numbers: [i64] = [1, 2, 3, 4];
print(numbers[0]);
print(len(numbers));

Example

fn main() {
    let a = 10;
    let b: i64 = 20;
    print(a + b);
    let active: bool = true;
    print(active);
    let name: string = "Nusa";
    print(name);
    let numbers: [i64] = [1, 2, 3, 4];
    print(numbers[0]);
    print(len(numbers));
}
Output30 true Nusa 1 4

Coba di playground

Rules

  • Gunakan let untuk semua binding lokal.
  • Anotasi wajib bila inferensi ambigu (konteks call/let/return).
  • Array homogen; len() builtin.

Compiler behavior

Semantic: scope + cek duplikat. TypeChecker: propagasi tipe konteks dua putaran untuk generik. OOB index → runtime error + exit 1.

Limitations

  • Tanpa float (i64 saja untuk angka).
  • String buram: tanpa ==/substring (lihat stdlib/string).
