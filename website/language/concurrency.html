Language / Concurrency

Concurrency

v3.0.0

Overview

Thread pthread + channel FIFO + mutex + atomik seq-cst + sleep sebagai 16 builtin (+chan_len di 2.7.0). Runtime C di-link otomatis (-pthread).

Syntax

let h = thread_spawn(work);
print(thread_join(h));
let c = chan_new();
chan_send(c, 1);
print(chan_len(c));

Example

fn main() {
    let c = chan_new();
    chan_send(c, 41);
    print(chan_len(c));
    print(chan_recv(c));
    chan_free(c);
}
Output1 41

Coba di playground

Rules

  • thread_spawn butuh fn() -> i64 ketat.
  • chan bertag: _bool/_str; mismatch = exit 1.
  • Handle basi/ganda/nol → runtime error: invalid handle + exit 1 (fail-fast 2.5.0).
  • chan_len race-tolerant by-design (cermin mutex_try_lock).

Compiler behavior

frontend::isBuiltin + checkBuiltin + genBuiltinCall; runtime nusa_chan_len + field size O(1) (simbol 29 → 30).

Limitations

  • Channel i64-centric; tanpa select/close/scoped-threads/pool.
  • Tanpa async/await (reserved, RFC-0004 Proposed); tanpa deteksi deadlock statis.
