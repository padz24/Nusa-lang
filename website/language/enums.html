Language / Enum

Enum

v3.0.0

Overview

Enum dengan payload posisional dan konstruktor qualified E.V(...). BREAKING 2.0: Option/Result kini enum natif di std (bukan struct); ctor lama none()/ok(v,d)/err(d,e) dan field .value/.has_value/.is_ok/.error DITOLAK.

Syntax

enum Color {
    Red, Green, Blue
}
let c = Color.Red;

enum Option<T> {
    Some(T), None
}
let o = Option<i64>.Some(5);

Example

enum Color {
    Red, Green, Blue
}
fn code(c: Color) -> i64 {
    match c {
        Red => {
            return 1;
        },
        Green => {
            return 2;
        },
        Blue => {
            return 3;
        },
    }
    return 0;
}
fn main() {
    print(code(Color.Red));
    print(code(Color.Green));
}
Output1 2

Coba di playground

Rules

  • Ctor wajib qualified: E<T>.V(args); V() = unit.
  • Bind kapital di pola = reinterpretasi varian.
  • Exhaustiveness seluruh varian wajib (pesan missing).
  • Tempa via struct literal/pola struct DITOLAK dengan hint.

Compiler behavior

Desugar ke hidden struct (tag + slot) pre-pass-1a; tanpa codegen baru kecuali toleransi field-hilang. print enum langsung ditolak (arahkan ke match).

Limitations

  • Ctor bukan first-class fn.
  • Tanpa payload bernama/or-pattern/range/repr; exhaustiveness top-level saja.
