Language / Error Handling

Error Handling

v3.0.0

Overview

enum Option<T> { Some(T), None } dan enum Result<T,E> { Ok(T), Err(E) } + kombinator bebas generik + operator propagasi expr? (khusus Result; Option/void/E-beda DITOLAK).

Syntax

import option;
let n = opt_unwrap_or(parse_int_opt("21"), 0);

fn get_age(s: string) -> Result<i64, string> {
    let n = parse_age(s)?;
    return Result<i64, string>.Ok(n + 1);
}

Example

import option;
fn main() {
    print(opt_unwrap_or(parse_int_opt("21"), 0));
    print(is_some(parse_int_opt("5")));
}
Output21 true

Coba di playground

Rules

  • ? hanya untuk Result dengan E sama antara operan dan return.
  • Kombinator: is_some/opt_unwrap_or/opt_map/is_ok/res_unwrap_or/res_map/res_map_err.
  • parse_int_opt/file_read_opt murni-Nusa; parse_int_valid konsisten strtoll.

Compiler behavior

? = uji tag + unwrap slot enum Result; struct-mirip tetap didukung untuk kompat. nusa fmt menempelkan ?.

Limitations

  • Tanpa exception/panic; tanpa konversi error otomatis; tanpa ? untuk Option.
  • Konstruktor butuh dummy di era struct 1.x (usang di 2.0).
