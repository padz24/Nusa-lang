Language Reference

12 topik · spec normatif language-spec-2.0 · Migrasi 1.x → 2.0

BREAKING 2.0 Option/Result struct → enum natif; ctor qualified; field lama ditolak; async reserved.

  • Syntax — Sintaks Nusa: item top-level (import, type, trait, impl, struct, enum, fn, extern fn), kom
  • Variables — Deklarasi dengan let, opsional anotasi tipe. Tipe dasar: i64, bool, string, array [T]. Ind
  • Functions — Fungsi top-level fn dengan param bertipe dan return eksplisit. Semua jalur harus return bi
  • Types — Static typing: i64/bool/string/void, fn, array [T], struct/enum bernama, dan alias type Na
  • Struct — Struct by-value dengan field publik. Konstruksi via literal Struct { field: value }. Metho
  • Enum — Enum dengan payload posisional dan konstruktor qualified E.V(...). BREAKING 2.0: Option/Re
  • Generics — Fungsi/struct generik dengan monomorphisasi per instansiasi konkret. Inferensi via unify +
  • Traits — trait T { fn m(self, ...) ...; } tanpa body; impl Trait for Type dengan resolve statis men
  • Pattern Matching — Statement match dengan pola literal int/bool/string, _, bind, struct, varian, dan guard if
  • Error Handling — enum Option<T> { Some(T), None } dan enum Result<T,E> { Ok(T), Err(E) } + kombinator bebas
  • Concurrency — Thread pthread + channel FIFO + mutex + atomik seq-cst + sleep sebagai 16 builtin (+chan_l
  • Modules — import math; memuat <dir>/math.ns (transitif). Modul flat namespace publik; dependensi pak
