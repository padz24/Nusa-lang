Language / Types

Types

v3.0.0

Overview

Static typing: i64/bool/string/void, fn, array [T], struct/enum bernama, dan alias type Name = T (transparan, forward-ref OK).

Syntax

type UserId = i64;
let u: UserId = 7;
let xs: [i64] = [1, 2];

Example

type UserId = i64;
fn main() {
    let u: UserId = 7;
    print(u);
}
Output7

Coba di playground

Rules

  • Alias dikanonikalisasi in-place (codegen tak berubah).
  • Circular alias ditolak dengan rantai A -> B -> A; chain > 100 ditolak.
  • Nama reserved tak boleh dipakai ulang.

Compiler behavior

TypeChecker resolusi alias eager + memo situs gagal (tepat satu error per masalah). ptr dikeluarkan dari grammar Type (handle = i64/string).

Limitations

  • Tanpa float, tanpa pointer yang dapat ditulis.
  • Tanpa union/cast numerik implisit.
