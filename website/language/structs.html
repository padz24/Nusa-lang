Language / Struct

Struct

v3.0.0

Overview

Struct by-value dengan field publik. Konstruksi via literal Struct { field: value }. Method via impl trait (dispatch statis).

Syntax

struct Person {
    name: string;
    age: i64;
}
let p = Person {
    name: "Nusa", age: 2
};
print(p.name);

Example

struct Person {
    name: string;
    age: i64;
}
fn greet(p: Person) -> string {
    return p.name;
}
fn main() {
    let p = Person {
        name: "Nusa", age: 2
    };
    print(greet(p));
    print(p.age);
}
OutputNusa 2

Coba di playground

Rules

  • Field selalu publik.
  • Struct di-passing by-value.
  • Method = trait impl (lihat Traits).

Compiler behavior

Layout LP64; hidden struct untuk enum (tag + slot payload). Field access di-resolve statis.

Limitations

  • Tanpa field array; tanpa param/return struct array-field; tanpa ==/print struct langsung (gunakan match/field).
  • Tanpa methods bawaan inheren.
