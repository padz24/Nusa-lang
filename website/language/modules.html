Language / Modules

Modules

v3.0.0

Overview

import math; memuat <dir>/math.ns (transitif). Modul flat namespace publik; dependensi paket via nusa.toml + lock + NUSA_PATH otomatis.

Syntax

// project/math.ns
fn add(a: i64, b: i64) -> i64 {
    return a + b;
}

// project/main.ns
import math;
fn main() {
    print(add(2, 3));
}

Example

fn main() {
    print("Hello, Nusa!");
}
OutputHello, Nusa!

Coba di playground

Rules

  • Merge dengan konflik nama = error.
  • Field struct selalu publik lintas modul.
  • Nama privat garis-bawah (_) tak diekspor.

Compiler behavior

ModuleLoader + resolver import bertitik (import std.time ≡ import time). Siklus/konflik ditolak jelas.

Limitations

  • Flat (tanpa subdir::/nested packages di era 1.x; paket via nusa pkg di 2.x).
  • import lokal nonaktif di mode playground.
