Language / Functions

Functions

v3.0.0

Overview

Fungsi top-level fn dengan param bertipe dan return eksplisit. Semua jalur harus return bila return type bukan void.

Syntax

fn add(a: i64, b: i64) -> i64 {
    return a + b;
}

Example

fn add(a: i64, b: i64) -> i64 {
    return a + b;
}
fn main() {
    print(add(10, 20));
}
Output30

Coba di playground

Rules

  • return all-paths ditegakkan checker.
  • Bare return; di tengah main legal (2.0).
  • Referensi fn meluruh menjadi closure pair saat dioper.

Compiler behavior

Mangled name untuk instansiasi generik dan method trait (Trait_method_Type). Panggilan tak langsung via trampolin (ptr env, ...).

Limitations

  • Hanya fungsi top-level (tanpa nested fn; gunakan lambda).
  • Tanpa default-arg/variadik.
