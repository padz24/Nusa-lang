Language / Traits

Traits

v3.0.0

Overview

trait T { fn m(self, ...) ...; } tanpa body; impl Trait for Type dengan resolve statis menjadi fungsi mangled. Koherensi unik program-wide.

Syntax

trait Show {
    fn show(self) -> string;
}
impl Show for A {
    fn show(self) -> string {
        return "A";
    }
}
fn f<T: Show>(v: T) -> string {
    return v.show();
}

Example

trait Show {
    fn show(self) -> string;
}
struct A {
    x: i64;
}
impl Show for A {
    fn show(self) -> string {
        return "A";
    }
}
fn f<T: Show>(v: T) -> string {
    return v.show();
}
fn main() {
    print(f(A {
        x: 1
    }));
}

Rules

  • self telanjang pertama wajib.
  • Target: struct/generik-konkret/primitif; array/fn/void ditolak.
  • Bound ganda dengan +.
  • Privacy _: nama garis-bawah = privat modul.

Compiler behavior

recv.method(args) → rewrite Trait_method_Type; codegen nol baris. Diagnostik unknown/ambiguous + daftar kandidat.

Limitations

  • Tanpa supertrait/body default/tipe Self/associated fn/dynamic dispatch.
  • Duplikat impl ditolak.
