Language / Syntax

Syntax

v3.0.0

Overview

Sintaks Nusa: item top-level (import, type, trait, impl, struct, enum, fn, extern fn), komentar // dan ///, dan operator ? => |. Keyword async/await di-reserved dan dilarang dipakai sebelum RFC-0004 Accepted.

Syntax

// komentar biasa
/// komentar dokumentasi (dipakai nusa doc)
import math;
fn main() {
    print("Hello, Nusa!");
}

Example

fn main() {
    print("Hello, Nusa!");
}
OutputHello, Nusa!

Coba di playground

Rules

  • Satu fn main tanpa param di biner akhir.
  • Item top-level boleh campur urutan.
  • Doc-comment /// dipertahankan formatter (jangan tulis ////).
  • Jangan pakai async/await sebagai identifier.

Compiler behavior

Lexer: token + flag doc-comment. Parser: lookahead untuk struct/import/literal/field, lambda, match arm, extern fn. Malformed input selalu exit != 0, rc <= 128 (tanpa sinyal) — dikunci e2e_stability (22 kasus, 16 pola fuzz manual).

Limitations

  • Nesting > 500 ditolak (too deeply nested).
  • Rantai import > 100 ditolak.
  • Tanpa break/continue; fungsi top-level saja.
