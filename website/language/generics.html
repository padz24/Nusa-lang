Language / Generics

Generics

v3.0.0

Overview

Fungsi/struct generik dengan monomorphisasi per instansiasi konkret. Inferensi via unify + eksplisit + mismatch per posisi.

Syntax

fn identity<T>(value: T) -> T {
    return value;
}

Example

fn identity<T>(value: T) -> T {
    return value;
}
fn main() {
    print(identity(41) + 1);
    print(identity("hi"));
}
Output42 hi

Coba di playground

Rules

  • Substitusi tparam menjangkau posisi-tipe ekspresi body (Option<U>.Some).
  • Bounds T: Trait dicek saat instansiasi konkret.

Compiler behavior

Monomorphisasi + recheck StructLit rewrite (tipe applied, bukan named-mangled). Dua putaran propagasi konteks.

Limitations

  • Tanpa metode/impl generik parsial; tanpa higher-kinded types.
  • Error bound: does not implement trait.
