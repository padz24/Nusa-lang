Language / Pattern Matching

Pattern Matching

v3.0.0

Overview

Statement match dengan pola literal int/bool/string, _, bind, struct, varian, dan guard if. Desugar ke let + rantai if/else (tanpa codegen baru).

Syntax

match x {
    1 => {
        return 10;
    },
    _ => {
        return 30;
    },
}

Example

fn f(x: i64) -> i64 {
    match x {
        1 => {
            return 10;
        },
        2 => {
            return 20;
        },
        _ => {
            return 30;
        },
    }
    return 0;
}
fn main() {
    print(f(1));
    print(f(9));
}
Output10 30

Coba di playground

Rules

  • Exhaustiveness wajib (bool + pasangan varian tertutup tanpa wildcard; literal butuh _).
  • Literal ganda + unreachable ditolak.
  • Guard boleh memakai binding arm.

Compiler behavior

Desugar flag ($matchK/$mK), inline guard (binding → klon aksesor murni), transparansi if true untuk all-paths.

Limitations

  • Statement-only (bukan ekspresi).
  • Tanpa or-pattern/range; varian enum pengguna sejak Phase 26.
