v3.0.0

22+ subperintah nusa v3.0.0. Sumber: nusa --help verbatim.

Nusa programming language v3.0.0 — Stable

Usage:
  nusa --version          Print version
  nusa --help             Print this help
  nusa build <file.ns> [-o <output>]   Compile to native executable
    [--profile <dev|debug|release>] [--link <lib|file>]... [--link-dir <dir>]...
    [--target <t>] [--sysroot <dir>] [--emit-ir|--emit-asm|-c]  Cross
    [-O0|-O1|-O2|-O3|-Os|-Oz]  LLVM optimization (default O0)
    [--fresh]  Ignore incremental cache
    [-g|--debug]  DWARF debug info
    [--stats]  Print compile-time breakdown (frontend/codegen/clang)
    [--pgo-generate]  PGO: build instrumented binary
    [--pgo-use <profdata>]  PGO: optimized build from profile
  nusa run <file.ns> [args...]  Build and run (args via process_argv)
  nusa bench <file.ns> [-n N] [-- args...]  Benchmark N runs (time + maxRSS)
  nusa check <file.ns>   Validate without compiling
  nusa trace run <file.ns> [args...]  Run with TRACE_ID injection
  nusa trace check <trace.log>  Validate nusa-trace log
  nusa repl                     Interactive read-eval-print loop
  nusa migrate [PATH]    Audit 2.x code for 3.0 (compatible/
                         deprecated/requires migration/broken/
                         unsupported; default: .)
  nusa clean [DIR]         Remove generated artifacts (*.ns.ll,
                                  .nusa-cache/, target/, dist/)
  nusa test [PATH...]    Run `*_test.ns` files (default: .)
  nusa fmt [--check] <file.ns>...      Format source files
  nusa doc <file.ns> [-o <out>] [--format markdown|json]  API docs/metadata
  nusa lsp                         Language server (LSP over stdio)
  nusa lex <file.ns>              Dump lexer tokens (debug)
  nusa ast <file.ns>              Dump parser AST (debug)
  nusa bindgen <header.h> [-o out.ns]  Generate extern fn bindings (C subset)
  nusa headers <file.ns> [-o out.h]  Generate C header from Nusa API (ABI-honest subset)
  nusa bootstrap [lex.ns] [-o DIR]  Stage 0->1->2 + repro check
    [--as lex|ast]  Stage-0 reference kind (default lex)
    [--rebuild DIR]  Stage 3: rebuild + compare (bootstrap full)
  nusa sandbox <file.ns> [--timeout S] [--memory-mb M] [--output-kb K]
                                  Run untrusted code under limits
  nusa playground [--port P] [--timeout S] [--memory-mb M]
                                  Local HTTP playground (127.0.0.1 only)
  nusa plugin run <file.ns> [--manifest m.json] [--timeout S]
                                  [--memory-mb M] [--output-kb K]
                                  Sandboxed JSON plugin (stdin request)
  nusa new <template> [name] [--dir DIR]  Scaffold a project
  nusa new --list                 List project templates
  nusa pkg <init|add|remove|update|build|publish|search|install|tree|verify|outdated|audit|sbom>  Package manager
  nusa search <query> [--registry DIR]  Search registry
  nusa install <name>[@req] [--registry DIR]  Add+update from registry
  nusa publish [--registry DIR]  Publish current package
  nusa tree                        Dependency graph
  nusa verify [--registry DIR]     Re-verify lock checksums
  nusa outdated [--registry DIR]   Newer registry versions
  nusa audit                       Capability + checksum report
  nusa sbom                        JSON supply-chain inventory (nusa-sbom/1)

Examples:
  nusa build examples/hello.ns
  ./hello
  nusa run examples/hello.ns
  nusa check examples/hello.ns
  nusa test tests/
  nusa fmt --check examples/hello.ns
  nusa pkg init myapp

Catatan pemakaian

  • build/run: --fresh abaikan cache; --stats rincian ms; -g DWARF; -O0..3/s/z.
  • playground/sandbox: hanya loopback + limit (lihat Playground).
  • pkg: butuh native = true untuk extern fn/[link].
